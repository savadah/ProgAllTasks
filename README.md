# ProgAllTasks

## Информация о репозитории

Этот репозиторий содержит материалы по дисциплине: **контесты**, **задачи** и **лабораторные работы**.

**Студент:** Сыров Кирилл

- **Язык программирования:** C#
- **Навигация по веткам:**
  - [`contest`](../../tree/contest) — контесты (решение в условиях ограниченного времени)
  - [`tasks`](../../tree/tasks) — задачи по теории и практике алгоритмов
  - [`labs`](../../tree/labs) — лабораторные работы

---

## Структура репозитория

1. **Контесты** — ветка [`contest`](../../tree/contest)
2. **Задачи** — ветка [`tasks`](../../tree/tasks)
3. **Лабораторные** — ветка [`labs`](../../tree/labs)
